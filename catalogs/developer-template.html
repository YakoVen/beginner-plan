Guide Développeur
Plan Débutant

Configuration, déploiement et personnalisation du store e-commerce Next.js.

1. Stack & Architecture

  • Framework : Next.js 15 (App Router)
  • Styling : Tailwind CSS & PrimeReact
  • Base de données : Firebase Firestore
  • Stockage fichiers : Firebase Storage
  • Authentification : Firebase Auth (Dashboard)

2. Installation Rapide

Installez les dépendances et configurez les variables d'environnement.

npm install
npm run dev

Variables d'environnement (.env.local)

NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project
NEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your_project.appspot.com
NEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id

Important : Le fichier serviceAccountKey.json est requis à la racine pour l'initialisation de Firebase Admin (Scripts de seed et middleware).

3. Personnalisation du Store

Toute la configuration textuelle, les liens sociaux et le prix de livraison sont centralisés dans le fichier service/constants.ts.

// service/constants.ts

export const store_name = "Mon Super Store";
export const store_url = "mondomaine.com";

export const delivery_price = 500; // Prix de livraison fixe (DZD)

export const store_description = "Bienvenue chez...";

// Catégories (Affichées dans le menu et la landing page)
export const categories = [
  { name: "Mode & Accessoires", thumbnail: "", icon: "" },
  { name: "High-Tech", thumbnail: "", icon: "" }
];

export const contact_info = {
    phone1: "0555000000",
    email: "contact@store.com",
    socials: [
        { platform: "instagram", link: "https://ig.com/store" },
        { platform: "facebook", link: "https://fb.com/store" }
    ]
}

Changer le Thème Global

Modifiez app/globals.css ou ajustez tailwind.config.ts pour modifier la palette de couleurs principale (actuellement configurée avec les classes utilitaires natives Tailwind).
